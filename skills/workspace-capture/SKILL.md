# Workspace Capture

Use this when the user asks to save, capture, track, file, remember as a task, or organize information.

Default command:
- `node skills/workspace-capture/scripts/capture.js note "text"`
- `node skills/workspace-capture/scripts/capture.js task "text"`
- `node skills/workspace-capture/scripts/capture.js decision "text"`

Prefer simple durable files over hidden state.
