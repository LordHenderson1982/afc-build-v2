# Workspace Map

- `START_HERE.md` — entry point for the human and agent.
- `AGENTS.md` — operating instructions loaded by OpenClaw.
- `IDENTITY.md` — agent identity.
- `USER.md` — human profile and preferences.
- `SOUL.md` — personality and behavior.
- `MEMORY.md` — curated long-term memory.
- `memory/` — daily notes.
- `Human/` — user-owned context, inbox, tasks, projects, people, resources, templates, and content.
- `Machine/Workflows/` — repeatable workflows.
- `Machine/Personalization/` — operator profile and agent personalization state.
- `Machine/Captures/` — saved notes/resources.
- `Machine/Scripts/` — safe deterministic helper scripts.
- `System/` — runtime, repair, diagnostics, channel setup, context/compaction, and version metadata.
- `System/workspace-os.json` — generated Workspace OS version/manifest metadata.
- `System/Composio.md` — connected app/tool identity workflow via agents.composio.dev.
- `skills/` — workspace skills and deterministic scripts.
